# 🎮 One More Game

One More Game is a browser-based gaming platform built with the MERN Stack and Unity WebGL, designed to bring together casual and competitive games in one place.

Instead of downloading individual games, players can instantly launch games in their browser, compete with friends, climb leaderboards, unlock achievements, and build a personal game library.

---

## ✨ Features

- 🎮 Browser-based games powered by Unity WebGL
- 🌍 Single-player and multiplayer experiences
- 🏆 Game-specific leaderboards
- 🏅 Achievement system
- 📚 Personal game library
- 🔍 Discover new games
- 👥 Friend system
- 🔔 Notifications
- ⚡ Real-time multiplayer with Socket.IO

## 🚀 Getting Started

Clone the repository

```bash
git clone <repository-url>
```

Install dependencies

```bash
npm install
```

Start the backend

```bash
cd server
npm run dev
```

Start the frontend

```bash
cd client
npm run dev
```

## 🎯 Vision

One More Game aims to become a modern browser gaming platform where users can instantly play games, compete with others, and discover new experiences without downloads or complicated setup.

The platform focuses on accessibility, replayability, and social interaction while maintaining a clean and immersive gaming experience.
